# Roadmap

This is a small extraction from an internal studio, released as version 0.1. These are directions, not shipped features or delivery promises.

1. Improve first-render reliability across operating systems and gather examples made by outside users.
2. Extract more shared typography, camera and transition helpers as real reusable APIs.
3. Add golden-still checks and additional cleared examples in distinct visual styles.
4. Improve audio workflows: measured word timings, recorded-voice onboarding and provider adapters.
5. Explore character rigs, lip-sync and depth-layer cameras once the underlying APIs are proven in multiple productions.

Keep Remotion as the renderer. Avoid creating many packages before the API has stabilized. Contributions should solve a reproducible production problem and keep the offline path simple.
