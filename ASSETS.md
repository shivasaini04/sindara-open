# Asset provenance

This release intentionally contains no production songs, voice recordings, AI plates, customer files, downloaded fonts, dataset snapshots or third-party reference frames.

| Material | Origin | Redistribution |
| --- | --- | --- |
| Starter SVG graphics, palette and procedural paper marks | Sindara project code by Shiva Saini | MIT, see LICENSE |
| `src/productions/data.json` | Synthetic fictional values created for this repository | MIT |
| `src/productions/timing.json` | Original demonstration event/caption data | MIT |
| `docs/preview.jpg` | Contact sheet rendered from this repository's starter compositions | MIT; system font software itself is not redistributed |
| Procedural demo audio, SFX and textures | Generated locally from project scripts, without downloaded samples | Project imposes no extra restrictions on generated output; retain code notices when redistributing the generators |
| System fonts used during rendering | Arial/Helvetica/sans-serif fallback supplied by the user's OS | No font files are distributed; rendering appearance varies by system |

The original private studio's story canon, experimental productions and reference media are outside this release. New media contributions must add a source, author, license and redistribution explanation here. Keep material with unclear rights out of pull requests.
